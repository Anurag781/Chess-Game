## 📖 Overview

Elevate your chess experience with this high-performance web application. Designed for speed and precision, **Chess Master Pro** combines the power of **Node.js** with the flexibility of **Tailwind CSS** to deliver a responsive, rule-strict environment for players of all levels.

- **Real-time Synchronization:** Built to handle moves instantly.
- **Visual Excellence:** High-fidelity board rendering and smooth transitions.
- **Pure Logic:** Zero room for error with industry-standard move validation.

---

## ✨ Features

- 🛡️ **Full Rule Support:** Handles En Passant, Castling, and Pawn Promotion effortlessly.
- ⚡ **Lightweight UI:** No heavy frameworks—pure HTML/EJS with Tailwind CDN optimization.
- 🚦 **Move Validation:** Integrated **Chess.js** prevents any illegal movement.
- 📱 **Fully Responsive:** Play on your desktop, tablet, or smartphone without losing focus.
- 🛠️ **Developer Friendly:** Modular folder structure for quick scaling.

---

## 🛠️ Tech Stack


| Technology | Usage |
| :--- | :--- |
| **Node.js** | Server-side runtime environment |
| **Express.js** | Web framework and routing |
| **Socket.io** | Real-time bi-directional communication |
| **EJS** | Dynamic template rendering |
| **Chess.js** | Core chess engine and logic |
| **Tailwind CSS** | Modern utility-first styling |
